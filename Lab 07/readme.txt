# Constructors in Python
- there are special function which get called automatically the moment we create an object
- there are first thing get executed while creating an object the class
- majorily we can use constructor to initialise the class variables

# type of constructor
1. default or non parameterized constructor
2. parameterized constructor

__init__()
- it is a special method in python which acts as a constructor
- it is called automatically when we create an object of the class
- it accepts the self keyword as a first argument which allow accessing the attributes or methods of the class
- we can pass any number of arguments at the time of creating the class object
- every class must have a constructor even if it simply relies in the default constructor
